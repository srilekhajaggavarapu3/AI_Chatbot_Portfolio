Stage 1 of 4

Simple One-Shot API Script

The foundation of the project. This script establishes secure environment configuration via `python-dotenv`, initializes the OpenAI client with custom base URLs (compatible with Ollama or local LLMs), and sends a single static prompt asking "what is AI?".

Environment variables (`.env`) loading
Custom endpoint configuration
Direct Chat Completions API call
Key Takeaway
Demonstrates secure API key handling and basic SDK integration without hardcoding secrets.
stage_1_basic.py 
from openai import OpenAI
from dotenv import load_dotenv
import os

# load the configuration from the .env file
load_dotenv()

# create a client that communicates with ollama/openai
client = OpenAI(
    base_url=os.getenv("base_url"),
    api_key=os.getenv("api_key")
)

# send a question to the ai model
response = client.chat.completions.create(
    model=os.getenv("model"),
    messages=[
        {
            "role": "user",
            "content": "what is AI?"
        }
    ]
)

print(response.choices[0].message.content)
Stage 2 of 4

Interactive CLI Loop

Upgraded from a single hardcoded question to a continuous interactive loop using `while True` and Python's `input()` function. Users can chat in real time and type "exit" to safely terminate the session.

Continuous execution loop (`while True`)
Dynamic user prompt input
Graceful exit condition handling
Key Takeaway
Transforms a static script into an interactive command-line application.
stage_2_input_loop.py 
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()

while True:
    user_input = input("ASK A QUESTION TO ANSWER: ")
    if user_input.lower() == "exit":
        print("byeeee... come again later take a break")
        break

    client = OpenAI(
        base_url=os.getenv("base_url"),
        api_key=os.getenv("api_key")
    )

    response = client.chat.completions.create(
        model=os.getenv("model"),
        messages=[
            {
                "role": "user",
                "content": user_input
            }
        ]
    )
    print(response.choices[0].message.content)
Stage 3 of 4

Conversational Memory

In Stage 2, every question forgot the previous context. Stage 3 introduces a `messages` array acting as conversation memory. Both user prompts and assistant replies are appended, enabling multi-turn context awareness.

Array-based state history tracking
Appending assistant responses to maintain context
Multi-turn conversational capability
Key Takeaway
Solves stateless API limitations by maintaining full chat history across loop iterations.
stage_3_memory.py 
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()

client = OpenAI(
    base_url=os.getenv("base_url"),
    api_key=os.getenv("api_key")
)

print("=" * 40)
print("       My AI Assistant")
print("=" * 40)

messages = []
while True:
    user_input = input("\nYou : ")
    messages.append({"role": "user", "content": user_input})

    if user_input.lower() == "quit":
        print("\nAI  : Goodbye! Have a great day.")
        break

    response = client.chat.completions.create(
        model=os.getenv("model"),
        messages=messages
    )

    ai_reply = response.choices[0].message.content
    print("\nAI :", ai_reply)
    
    messages.append({"role": "assistant", "content": ai_reply})
Stage 4 of 4

Persona-Based AI Assistant

The ultimate iteration. Introduces a dynamic role dictionary (`roles` dict) allowing users to pick a specialized AI persona (Teacher, Python Expert, Travel Guide, Motivational Coach, Interviewer) which initializes the message stack with a custom `system` prompt.

System role prompt injection
Dictionary-based persona routing
Customizable expert behavior
Key Takeaway
Demonstrates advanced LLM control through system instructions and modular dict lookup.
stage_4_personas.py 
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()
client = OpenAI(base_url=os.getenv("BASE_URL"), api_key=os.getenv("API_KEY"))

roles = {
    "1": "You are a friendly school teacher. Explain concepts simply with real-life examples.",
    "2": "You are a senior Python developer. Explain clearly with code examples.",
    "3": "You are an experienced travel guide. Recommend places, food, and tips.",
    "4": "You are a motivational coach. Encourage the user positively.",
    "5": "You are a professional interviewer. Ask one question at a time."
}

print("Choose Assistant:\n1. Teacher\n2. Python Expert\n3. Travel Guide\n4. Coach\n5. Interviewer")
choice = input("\nEnter choice: ")

messages = [{"role": "system", "content": roles.get(choice, "You are helpful.")}]

while True:
    user_input = input("\nYou : ")
    if user_input.lower() == "quit": break
    messages.append({"role": "user", "content": user_input})
    
    res = client.chat.completions.create(model=os.getenv("MODEL"), messages=messages)
    reply = res.choices[0].message.content
    print("\nAI :", reply)
    messages.append({"role": "assistant", "content": reply})
